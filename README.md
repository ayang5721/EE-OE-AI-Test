# EE-OpenAI-API-RAG-Test

This repository contains a chatbot model test for Ross Executive Education Open Enrollment chatbot implementation. This model utilized Gpt-4.1 from OpenAI and uses RAG for context for the model.

This repository contains files for audio to text translation. The purpose is to take audio and turn it into text files so the model can be trained using that text/use those text files as RAG.

## Important Rules

All context files must be added in the documents folder as .txt files
